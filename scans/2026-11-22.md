# Daily AI tools scan: 2026-11-22

Today leans into Fuse's business side (ads, analytics, media), plus one web-dev pick.

## Picks

1. **[Canva plugin + Canva MCP](https://claude.com/marketplace/plugins/canva)** (established, official Canva, Anthropic-verified; source: [canva-sdks/canva-skills](https://github.com/canva-sdks/canva-skills); server `https://mcp.canva.com/mcp`)
   Lets Claude create, edit, resize (one step for Facebook/Instagram/LinkedIn), and brand-check Canva designs, with a preview-and-approve step before any edit lands. For Fuse: quick ad and social creatives for launch and for business customers, plus a brand-kit check against Fuse's look. Bulk-create from a spreadsheet needs Canva Enterprise; resize/autofill tools need Pro or higher.

2. **[TikTok for Business MCP](https://business-api.tiktok.com/portal/docs/how-to-connect-a-custom-agent-to-tiktok-for-business-mcp-server/v1.3)** (established, official TikTok; MCP since May 2026, in [Claude's connector directory](https://claude.com/marketplace/connectors/tiktok-for-business) since Oct)
   About 400 tools for campaigns, reporting, creatives, audiences, and Business Center, over OAuth (no API key). It rounds out the Google Ads + Meta Ads MCPs from yesterday, so Fuse's ads/analytics product can pull TikTok reporting into the same agent workflows. Needs a TikTok for Business account; the sign-in lasts 30 days.

3. **[kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill)** (GitHub, new and trending, MIT, ~9.4k stars, created Sep 2026)
   A local video editor for Claude Code: 42 FFmpeg tools plus an MCP server (cut, captions, 9:16 reframe, loudness, platform exports), and it measures its own output. No cloud, no API keys. For Fuse: turn venue or event footage into Reels/TikTok-ready ad clips for the media-management side, all on your machine.

4. **[Modern Web Guidance](https://developer.chrome.com/docs/modern-web-guidance)** (GitHub: [GoogleChrome/modern-web-guidance](https://github.com/GoogleChrome/modern-web-guidance), new and trending, Apache-2.0, ~24.8k stars; run by the Chrome, Edge, Firefox, and MDN teams)
   Agent skills that push Claude toward modern browser APIs (View Transitions, popover/dialog, container queries) and away from heavy JS and polyfills, plus a `legacy-scan` to find old patterns. For Fuse: leaner, more accessible web prototype and business dashboards. Needs Node 22+.
