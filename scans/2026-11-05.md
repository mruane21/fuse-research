# Fuse daily AI tools scan: 2026-11-05

## 1. Palaner MCP (events data for Claude): new
[Palaner MCP](https://palaner.com/mcp) gives Claude one-call access to roughly 250,000 upcoming events pulled from 90+ sources (Eventbrite, Meetup, Ticketmaster, Bandsintown, Luma and more). It searches by coordinate and radius, so Huntington Village works even though it has no city page. It also has a `find_group_venue` tool that picks a venue that's fair for several people, which is close to Fuse's group-matching idea. Free tier is 100 searches a month and needs a Palaner sign-in (OAuth in the browser). Coverage on Long Island is unverified, so test it before relying on it, and check its terms before storing results in Fuse.

## 2. Scrapling and its MCP server (GitHub project): established
[D4Vinci/Scrapling](https://github.com/D4Vinci/Scrapling) is a popular Python scraping framework, and its [MCP server](https://scrapling.readthedocs.io/en/latest/ai/mcp-server.html) lets Claude Code fetch pages (plain HTTP or a stealth browser), extract by CSS selector, and inspect network calls. For Fuse it's a free way to build and refresh plan-card data for Huntington Village (menus, happy hours, event pages) from venue sites. It strips hidden prompt-injection text by default. Check each site's robots.txt and terms first and ask venues when you can.

## 3. Apify MCP server: established
[apify/apify-mcp-server](https://github.com/apify/apify-mcp-server) ([docs](https://docs.apify.com/platform/integrations/mcp)) is a hosted MCP server that exposes thousands of ready-made scrapers from the Apify Store, including Google Maps places, Yelp, Eventbrite and social media. It's the lower-effort alternative to Scrapling when you'd rather run a maintained scraper than write selectors. It signs in with OAuth, so no key has to sit in a file, and the free plan has a small monthly credit.

## 4. Genkit 1.44 and Firebase AI Logic App Check (Firebase AI tooling): established
[Genkit 1.44.0](https://github.com/genkit-ai/genkit/releases) shipped Nov 3 with Gemini Deep Research support, Word and Excel inputs, and better token reporting. Separately, Firebase began enforcing App Check for [Firebase AI Logic](https://firebase.google.com/docs/ai-logic/app-check) on Nov 2, 2026, so any web app calling Gemini from the client without App Check will get blocked requests (delay is possible until Jan 21, 2027). If Fuse adds AI features such as match blurbs or "why this plan" text, that's the Firebase-native route, and it's worth knowing the App Check requirement up front. Nothing to install today; the prompt below only does a read-only check.

## Copy-paste prompt for Claude Code
Run from `C:\Users\User\fuse` in PowerShell, then paste:

```
You're helping set up research tooling for Fuse (Fuseplans), a Firebase web app, on Windows/PowerShell, working from C:\Users\User\fuse. Rules: ask me before changing any app code, package.json, or Firebase config, and before making any git commit. Never write API keys or tokens into files; if a key is ever needed, tell me to store it as a Windows user environment variable (setx NAME value) and reference it as ${NAME} in .mcp.json.

1. Palaner events MCP: run `claude mcp add --transport http palaner https://api.palaner.com/mcp`. Tell me to run /mcp afterwards and finish the browser sign-in. Don't ask for any password.
2. Apify MCP: run `claude mcp add --transport http apify https://mcp.apify.com`. Authentication is browser OAuth through /mcp. Don't use an API token unless OAuth fails; if it does, tell me to set a Windows user env var APIFY_TOKEN and reference it as ${APIFY_TOKEN} in a header.
3. Scrapling MCP: check Python with `python --version`. If it's missing, stop and tell me. Otherwise run `pip install "scrapling[ai]"`, then `scrapling install`, then register it with `claude mcp add ScraplingServer (Get-Command scrapling-mcp).Source`. If the command isn't found, find the full path with `where.exe scrapling-mcp` and use that.
4. Firebase AI Logic check (read-only, change nothing): search this project for firebase/ai or Firebase AI Logic usage and any App Check setup. Report whether the app calls Gemini from the client and whether App Check is initialized. Only propose changes; don't make them.
5. Finish with `claude mcp list` and show me the output. Tell me which servers show Connected and which still need sign-in.
```
