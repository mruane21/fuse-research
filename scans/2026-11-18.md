# Fuse AI tools scan: 2026-11-18

1. **Claude Code v2.1.327** (new, released Nov 17): https://code.claude.com/docs/en/changelog
   The new `claude mcp add-json <name> -` reads a server's JSON config from stdin, so tokens no longer show up in your shell history or command line. That fits your rule of keeping keys only in env vars. `/status` now also lists broken skills, agents, hooks and ignored permission settings, and `ExitWorktree` asks before it removes a worktree that might have unsaved work. Run `claude update`.

2. **Novu + Novu MCP** (established, open source, ~40k stars): https://github.com/novuhq/novu · MCP docs: https://docs.novu.co/platform/build-with-ai/mcp
   A notification platform that handles push, email, SMS, chat and an in-app inbox in one place, with workflows, digests and per-user preferences. Fuse could use it for "your group matched on a plan" and "vote closes soon" alerts, and later for advertiser reports and campaign alerts on the business side. The hosted MCP (OAuth, `https://mcp.novu.co/`) lets Claude Code create workflows, trigger test sends and debug failed deliveries.

3. **ClickHouse Cloud remote MCP + mcp-clickhouse** (established; open-source server updated Nov 16): https://clickhouse.com/docs/products/cloud/features/ai-ml/remote-mcp · https://github.com/ClickHouse/mcp-clickhouse
   ClickHouse is the usual columnar database behind ad and event analytics: impressions, swipes and clicks per venue, at volumes Postgres starts to struggle with. The managed MCP at `https://mcp.clickhouse.cloud/mcp` (OAuth, scoped read-only SELECT queries) lets Claude look at schemas and write advertiser-report queries while you prototype the analytics product. The open-source server works with any ClickHouse instance, including a free local one.

4. **Univer** (GitHub project, established, Apache-2.0, ~29.8k stars, #1 TypeScript repo on GitHub trending today): https://github.com/dream-num/univer
   An embeddable spreadsheet and docs SDK (formulas, editing, a Facade API that agents can drive) that you add with `@univerjs/presets`. For the business dashboard, venues could open their campaign and analytics data as an editable sheet inside Fuse instead of exporting CSVs. It runs in the browser only, so it's for the web admin, not the React Native app.
