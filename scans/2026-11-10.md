# Fuse daily AI tools scan — 2026-11-10

1. **Claude Code v2.1.321 / v2.1.322** (new) — [changelog](https://code.claude.com/docs/en/changelog)
   v2.1.321 makes Claude Fable 5.2 (`claude-fable-5-2`, 1M context) the default Fable model and adds `claude remote-control --settings <file>`, so remote sessions can inherit the same "ask before app code / package.json / Firebase config / commits" permissions you use locally. v2.1.322 adds fast mode on Vertex. Worth updating before your next big Fuse session.

2. **Google Developer Knowledge MCP** (established, official Google, public preview) — [setup docs](https://developers.google.com/knowledge/mcp)
   Hosted MCP that searches and returns official Google developer docs (Firebase, Google Cloud, Maps Platform, Android) as Markdown. Complements the Firebase MCP you already have: Claude can pull current docs for SQL Connect, Functions, Hosting and Secret Manager instead of guessing from stale training data. Needs a Google Cloud API key restricted to the Developer Knowledge API.

3. **Snyk Agent Scan** (established GitHub project, actively maintained) — [snyk/agent-scan](https://github.com/snyk/agent-scan/)
   CLI that auto-discovers your Claude Code MCP servers and skills and scans them for prompt injection, tool poisoning, hardcoded secrets and malicious payloads. You've added a lot of MCPs and plugins in the last two weeks, so a one-time audit (and re-running it after each new install) is cheap insurance. Note: it starts stdio MCP servers to read their tool lists, and asks consent for each one.

4. **Shopify FlashList** (established GitHub project) — [Shopify/flash-list](https://github.com/Shopify/flash-list)
   Drop-in, much faster replacement for React Native's FlatList that recycles cells. Good fit for Fuse's plan lists, match results and group feeds as Huntington Village venue counts grow, and it works with Expo. This one touches package.json, so it's a "review and decide" pick.
