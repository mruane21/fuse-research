# Daily AI tools scan: 2026-11-25

Today: Claude Code v2.1.332 (out this morning) lets MCP servers ship their own skills. Also Mux's hosted MCP for video hosting and video analytics, Metabase's built-in MCP for customer-facing analytics, and two GitHub dev-workflow tools: Plannotator for reviewing agent plans and Alibaba's Open Code Review.

## Picks

1. **[Claude Code v2.1.332](https://code.claude.com/docs/en/changelog)** (new, released 2026-11-25)
   Adds **skills from MCP servers (beta)**. They show up as `server:skill` in the `/` menu, so the MCPs you already use can bring their own playbooks with them. There's also a new `PreSkillShellCommand` hook that can block a skill's inline shell commands when the skill loads, which fits your "ask before changing things" rules. Run `claude update` and check `/` for any new `server:skill` entries.

2. **[Mux MCP server](https://www.mux.com/docs/integrations/mcp-server)** (established company; hosted remote MCP at `https://mcp.mux.com`)
   Video hosting, uploads, live streams and **Mux Data** video analytics (views, engagement by country, playback errors), all through one MCP. It uses "Code Mode": two tools that run TypeScript against the full `@mux/ts` SDK. For Fuse's media-management side, Mux could host and stream businesses' video ads and promo clips, and report how they performed, without you building a video pipeline. It signs in with OAuth (no key), and its permissions match the Mux environment and token you authorize. It doesn't treat destructive actions any differently, so use a read-only token if you want it to only look.

3. **[Metabase](https://github.com/metabase/metabase) + its [built-in MCP server](https://www.metabase.com/docs/latest/ai/mcp)** (established open-source BI; the MCP is on by default in recent versions)
   This is a mature, open-source BI and embedded-analytics tool. It can point at your Postgres (SQL Connect) and become the analytics dashboards that Fuse's business customers see. The MCP (`/api/metabase-mcp`) signs agents in *as a person*, so they only see what that user can see and they reuse the metrics you've already defined. That's safer than giving Claude raw database credentials. The MCP is on every plan, and per-group tool limits need Pro/Enterprise. You can try it locally with Docker.

4. **[Plannotator](https://github.com/backnotprop/plannotator)** (established, actively trending GitHub project; [site](https://plannotator.ai))
   A local browser surface for reviewing what Claude Code proposes. You can annotate plans, specs and HTML, review diffs with guided chapters, and even mark up your running localhost app. Your comments go back to the agent. It suits a design-led CTO: you comment visually on the prototype or a plan instead of typing long corrections. It has a Windows PowerShell installer and a Claude Code plugin.

5. **[Open Code Review](https://github.com/alibaba/open-code-review)** (new open-source release of Alibaba's internal tool; [site](https://open-codereview.ai))
   An AI code-review CLI and Claude Code plugin. It combines deterministic pipelines with an LLM agent and gives line-level comments (XSS, SQL injection, null-pointer checks and more). Alibaba's benchmark claims higher precision than plain Claude Code for about 1/9 of the tokens. Its "delegate" mode uses Claude Code's own model, so you need no extra API key. It's a cheap second pair of eyes before you commit Fuse changes.

```text
1) Claude Code update: run claude --version, then claude update. Confirm I'm on 2.1.332 or newer. Tell me which MCP-provided skills (shown as server:skill in the / menu) are now available from my existing MCP servers. Don't add any hooks or settings changes without asking.

2) Mux MCP (hosted, OAuth, no key): claude mcp add --transport http --scope user mux https://mcp.mux.com . 4) Plannotator: show me the installer first, then run it in PowerShell: irm https://plannotator.ai/install.ps1 | iex . Show me how to annotate my running app with: plannotator annotate http://localhost:<port> .

5) Open Code Review: npm install -g @alibaba-group/open-code-review (global CLI only, NOT in the project's package.json). Then claude plugin marketplace add alibaba/open-code-review and claude plugin install open-code-review@open-code-review . Use delegate mode (/open-code-review:delegate-review) so it uses Claude Code's model and no extra API key. Do one trial review of my current uncommitted changes and report the findings. Don't fix anything without asking.

Finish by running: claude mcp list
```
