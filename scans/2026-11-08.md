1. **Maestro + Maestro MCP** (established, open source) — https://github.com/mobile-dev-inc/maestro · MCP docs: https://docs.maestro.dev/get-started/maestro-mcp
   Expo's recommended E2E testing tool, and the MCP server ships inside the CLI (`maestro mcp`). Claude Code can drive the Fuse app on an Android emulator or the web build, tap through the swipe-and-match flow, check its own work, and save the run as a YAML test you can later run in EAS Workflows on every PR.

Installs as Claude Code plugin bundles, so Claude follows proven RN patterns when touching Fuse's Expo code.

3. **Parallel MCP 2.0** (new, launched Nov 5, 2026) — https://parallel.ai/blog/parallel-mcp-2 · setup: https://docs.parallel.ai/integrations/mcp/quickstart
   One free, keyless MCP for web search, page fetch, and grounded "decisions"; signing in adds deep research. Handy for researching Huntington Village venues and events to seed plan cards, or checking competitors, without paying for an API key.
