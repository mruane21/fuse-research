# Fuse AI tools scan — 2026-11-17

1. **Firecrawl MCP v3** (established tool, new v3 released Nov 12, 2026) — https://www.firecrawl.dev/blog/firecrawl-mcp-v3 · setup: https://docs.firecrawl.dev/mcp-server/connect
   One hosted MCP (OAuth sign-in, no key needed) for search, scrape, and a 3,000+ tool data catalog (company and people data). Fuse can use it to pull Huntington Village venue menus, hours, and event pages into plan cards, and Joe can use it to research local businesses to pitch the ads and analytics product.

2. **Serena** (established, MIT, Anthropic-verified Claude plugin) — https://github.com/oraios/serena · https://claude.com/plugins/serena
   A language-server-backed MCP that gives Claude Code symbol-level tools (find symbol, find references, rename, replace body) for TypeScript. It saves tokens and cuts bad edits in the Expo/RN codebase, and helps most with refactors as Fuse moves into business software.

3. **stalemap** (GitHub project, new, v0.4.1, early, one maintainer) — https://github.com/Umair/stalemap · https://www.npmjs.com/package/stalemap
   Finds which dependencies changed after the model's training cutoff (Expo SDK, React Native, Firebase, zod and others) and gives Claude the notes, plus a type-check after each edit. Its own benchmark: 89% of tasks passed with it vs 68% without. That means fewer "old API" bugs in Fuse.

4. **Payload CMS + @payloadcms/plugin-mcp** (established, open source, Postgres adapter) — https://payloadcms.com/docs/plugins/mcp · https://www.npmjs.com/package/@payloadcms/plugin-mcp
   A headless CMS and admin panel with built-in media uploads, plus an official plugin that turns its collections into MCP tools with per-operation permissions. It's a good base for the business-side ad and media management dashboard (venue creatives, campaigns), and Claude can manage the content directly. Try it in a sandbox before committing to it.
