# Fuse AI tools scan — 2026-11-02

1. **[Context7 MCP + plugin](https://github.com/upstash/context7)** (established, very widely used). Feeds Claude Code current, version-specific docs for the Firebase JS SDK, Firestore rules, and whatever front-end libraries Fuse uses, so it stops writing outdated Firebase v8-style code. The hosted server signs in with OAuth, so no API key is needed.

2. **[Figma MCP server (remote)](https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/)** (established, Figma's official server). Since you own design and brand, Claude Code can read your Figma frames, variables, and components directly and build plan cards and screens that match the brand, instead of working from screenshots. It signs in with your Figma account through OAuth.

3. **[PostHog Claude Code plugin + MCP](https://posthog.com/docs/model-context-protocol/claude-code)** (established, in Anthropic's plugin marketplace). Ahead of the Huntington Village launch you can ask Claude about swipe-to-match funnels, drop-off, and errors, and create feature flags or A/B tests (for example card order or match thresholds) from a prompt. PostHog's free tier covers early traffic, it signs in through OAuth, and you'd still add the PostHog snippet to the app separately.

4. **[liketrek/TREK](https://github.com/liketrek/TREK)** (GitHub, about 15k stars, actively updated through Nov 1). This open-source group travel planner has real-time WebSocket collaboration, group polls, place search with no key, and an offline PWA, which makes it a good reference for how Fuse groups vote and sync live. It's AGPL-licensed, so study the patterns but don't copy its code into Fuse.

5. **Anthropic news (new, Oct 30–31):** Claude's Max 5x plan is now just "Max" ($100) and Max 20x is now "Ultra" ($200). [Verified Ultra accounts no longer have the 5-hour limit](https://ailookout.news/blog/anthropic-renames-claude-max-plans-ultra-drops-the-five-hour-limit/), but weekly limits haven't changed. You don't need to do anything, but it matters if long Claude Code sessions keep hitting the 5-hour cap. There's no new Claude Code release since v2.1.316.

## Claude Code setup prompt (run from `C:\Users\User\fuse`)

```
I'm on Windows/PowerShell in C:\Users\User\fuse. Set up these tools for my Fuse project. Do NOT change any app code, package.json, or Firebase config, and don't commit anything without asking me first. Only touch Claude/MCP config. Never write a literal API key into any file; if anything needs a key, ask me for it, have me store it as a Windows user environment variable myself with [Environment]::SetEnvironmentVariable('NAME','<key>','User'), and reference it as ${NAME} in config.

1. Context7: add the hosted OAuth server for my user with `claude mcp add --scope user --transport http context7 https://mcp.context7.com/mcp/oauth`. Then optionally install the plugin (ask me first): `claude plugin marketplace add upstash/context7` and `claude plugin install context7-plugin@context7-marketplace`.
2. Figma: `claude mcp add --scope user --transport http figma https://mcp.figma.com/mcp`.
3. PostHog: `claude plugin install posthog` (if it's not found, fall back to `claude mcp add --scope user --transport http posthog https://mcp.posthog.com/mcp`). Don't add the PostHog snippet to the app; just tell me what it would take.
4. TREK (reference only): don't clone or install anything. Just give me a 5-bullet summary of how https://github.com/liketrek/TREK handles real-time group sync and polls that I could adapt for Fuse in Firestore, and note that it's AGPL so no code should be copied.
5. Tell me to run /mcp inside Claude Code and choose Authenticate for context7, figma, and posthog. Wait for me to confirm.
6. Finish by running `claude mcp list` and showing me the output, plus a one-line note on anything that failed.
```
