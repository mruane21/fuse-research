# Fuse AI tools scan: 2026-11-13

1. **Claude Code v2.1.323: Code Mode** (new, Nov 12): https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
   Claude can now write JavaScript to call its tools. It's an experimental opt-in, so many-step jobs (batch Firebase/SQL Connect checks, scripted MCP calls) could take fewer round trips. The same release lets plugins pin a Claude Code version range with `engines["claude-code"]`. The Code Mode docs page linked from the changelog (code.claude.com/docs/en/code-mode) wasn't live yet when I checked.

2. **Storybook for React Native v10 + Storybook MCP** (established; MCP is newer): https://github.com/storybookjs/react-native · docs: https://storybook.js.org/docs/ai/mcp/overview
   You can build and review Fuse's plan cards, swipe deck and group screens one component at a time, without running the whole app. The experimental `/mcp` endpoint (localhost:7007) lets Claude Code read your component props and stories, so new UI matches your design system.

3. **Linear MCP (official)** (established): https://linear.app/docs/mcp
   A hosted server at `https://mcp.linear.app/mcp` that signs in with OAuth (no API key). It gives you and Joe a shared launch board that Claude Code can read and update: it can turn bugs it finds into issues or pull the next task. There's a read-only endpoint (`/mcp/readonly`) if you want it safer.

4. **Nutlope/hallmark** (GitHub, trending, v2): https://github.com/Nutlope/hallmark
   A design skill (by Together AI) with 50 themes and a "sloplint" browser check. It flags generic AI-looking layouts and runs a hard floor on contrast, focus, motion and phone layout. Useful for the Fuse landing/waitlist page and Huntington Village launch pages: `/hallmark audit <path>` only reports and changes nothing.

5. **addyosmani/agent-skills** (GitHub, ~117k stars, trending): https://github.com/addyosmani/agent-skills
   25 engineering skills behind `/spec`, `/plan`, `/build`, `/test`, `/review`, `/ship`. Good for shipping features like group matching or invites as small tested pieces before launch. It installs as a Claude Code plugin, and the built-in `/review` stays separate as `/agent-skills:review`.

## Claude Code prompt

```text
Run from C:\Users\User\fuse (Windows, PowerShell). Set up today's tools. Rules: ask me before changing any app code, package.json, Firebase config, or before committing. Any API key lives only in Windows user env vars and is referenced as ${VAR} in .mcp.json, never as a literal.

1. Claude Code update + Code Mode: run `claude update`, then `claude --version` (want >= 2.1.323). Read https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md (2.1.323) and https://code.claude.com/docs/en/code-mode. Tell me exactly how to opt in to Code Mode (setting or flag) and propose the change; don't apply it until I say yes.
2. Linear MCP: `claude mcp add --transport http --scope user linear https://mcp.linear.app/mcp` (OAuth, no key). Then tell me to run /mcp to sign in. If I'd rather start read-only, use https://mcp.linear.app/mcp/readonly instead.
3. Storybook for React Native + MCP: DON'T install yet. Check the Expo app for an existing Storybook, then show me the plan: `npx storybook@latest init` (React Native), the `.rnstorybook` files it creates, the package.json changes, and the metro.config.js change `withStorybook(config, { websockets: { port: 7007 }, mcp: true })` (or `experimental_mcp`). Wait for my OK. After it's set up, add the MCP: `claude mcp add --transport http --scope project storybook http://localhost:7007/mcp`.
4. Hallmark design skill: `npx skills add nutlope/hallmark -g` (needs Node 18+; optional `npm i -g puppeteer-core` for browser checks, so ask me first). Then run `/hallmark audit` on our web/landing page as a report only, with no edits.
5. Addy Osmani agent-skills: in Claude Code, `/plugin marketplace add addyosmani/agent-skills` then `/plugin install agent-skills@addy-agent-skills`. Show me the commands it adds.
6. Finish with `claude mcp list` and summarize what's connected and what still needs sign-in.
```
