### 1. Expo MCP Server + Expo Skills — established
- Docs: https://docs.expo.dev/mcp/
- Skills: https://docs.expo.dev/skills

- Docs: https://findlocal.community/mcp
- MCP URL: `https://mcp.findlocal.community/mcp` (Streamable HTTP + OAuth; free API key)
