# Fuse AI tools scan — 2026-11-27

No new Claude Code release since v2.1.332 (covered 11-25). Anthropic's Claude Ship beta (Nov 23) is for Team and Enterprise only, so it's skipped.

## Picks

1. **Runway MCP (official)** (established; launched May 27, Runway Ads went GA Oct 27): https://runway.com/mcp · [launch post](https://runway.com/news/company-news/mcp)
   Claude can generate images and video with Gen-4.5, Kling, Veo, Nano Banana Pro and more from a product URL, a photo or a prompt. Sign-in is OAuth with no API key, and each generation spends Runway credits. For Fuse's ad and media pivot, it can draft ad creatives and short promo videos for Huntington businesses, using their own photos as references. That makes it a fast way to prototype a "make my ad" feature before building one.

2. **Google Workspace MCP servers + official Workspace CLI (`gwscli`)** (new, GA Nov 24): [announcement](https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html) · [CLI guide](https://developers.google.com/workspace/guides/workspace-cli) · [MCP tools](https://developers.google.com/workspace/guides/mcp-server-tools)
   These are Google-hosted MCP servers for Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat and Tasks, plus a terminal CLI with packaged agent skills that confirms sensitive actions before running them. The Standard tier is free. Joe's business-side work lives here: lead sheets of local businesses, outreach email, meeting scheduling, pitch decks. Claude Code can draft and update all of it.

3. **DIYgod/pinky** (GitHub, new, ~2.8k★, Apache-2.0, released daily; latest v2026.1127.5): https://github.com/DIYgod/pinky
   Pinky lets Claude Code operate a real Android phone or iPhone, or an emulator, over MCP. You watch the mirror, take over at any time, and approve risky steps. It has a Windows build and connects to Claude Code in one click (Settings › Agents). Claude could tap through the Expo app's swipe deck and group-match flow on a real device and report bugs. Unlike scripted Maestro tests, it explores the way a user would.

4. **Google Business Profile APIs** (established): https://developers.google.com/my-business
   These are the official APIs behind business listings on Google Search and Maps: locations, hours, photos, reviews, posts, and performance data like calls, website clicks and search terms. Fuse could let a business connect its profile to auto-fill plan cards and show Google performance next to Fuse ad stats in the business dashboard. Access needs an approved API application, so Joe should apply early. Google publishes no official MCP for it; the third-party ones are small and unvetted, so build against the API directly.
