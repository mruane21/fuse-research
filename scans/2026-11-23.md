# Daily AI tools scan: 2026-11-23

Today: an App Store/Play guard for the Expo app, a codebase-health MCP, a social-listening research skill, and one business-side email/SMS MCP. No new Claude Code release since v2.1.330 (covered 11-21).

## Picks

1. **[mjmirza/app-store-compliance](https://github.com/mjmirza/app-store-compliance)** (GitHub, newer and trending: ~4.4k stars, created Jun 2026, v2.5.1 shipped Nov 22; [website](https://mjmirza.github.io/app-store-compliance/))
   A pre-submission guard plus a Claude Code skill and `/app-store-audit` command, with 124 documented App Store/Google Play rejection patterns, privacy-manifest and Data safety checks, and tracked deadlines (COPPA, age laws, EU AI Act). For Fuse: run it on the Expo app before the first TestFlight/Play submission so you catch rejection causes (sign-in, account deletion, location/privacy strings) early. Notes: it needs git + bash (Git Bash on Windows), its installer adds a hook to `~/.claude/settings.json` that blocks submit commands until the scan passes, and the repo has no standard license.

2. **[fallow-rs/fallow](https://github.com/fallow-rs/fallow)** (GitHub, MIT, ~5.4k stars, very active: v3.47.0 released today; [MCP docs](https://fallow.tools/docs/integrations/mcp/))
   A fast Rust tool for TypeScript/JavaScript: unused files/exports/deps, duplication, complexity hotspots, circular deps, and design-system drift, with an MCP server so Claude can check what's truly unused before deleting or refactoring. For Fuse: keep the Expo + Firebase codebase lean as it pivots toward business dashboards. Only its `fix_apply` tool changes files.

3. **[mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill)** (GitHub, established and trending, MIT, ~73k stars, v4.6.0 on Nov 22)
   A `/last30days` Claude Code plugin that researches any topic across Reddit, X, YouTube, Hacker News and the web, then writes a grounded summary. For Fuse: quick market reads for you and Joe, like "what Huntington/Long Island restaurants and bars say about ad tools" or how competitors are being talked about. Core sources need no API key; extras (e.g. Telegram) need their own keys.

4. **[Klaviyo MCP server](https://developers.klaviyo.com/en/docs/klaviyo_mcp_server)** (established, official remote MCP at `https://mcp.klaviyo.com/mcp`; [agent setup](https://developers.klaviyo.com/en/agents))
   Lets Claude read campaign and flow performance and draft email/SMS campaigns in a Klaviyo account. For Fuse's business side: a model for pulling a business's email/SMS results into the same analytics view as the Google/Meta/TikTok ads MCPs. Partial fit: Klaviyo leans toward ecommerce, so it matters most if your business customers already use it. Needs a Klaviyo account (OAuth sign-in).
