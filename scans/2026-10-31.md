- [PredictHQ MCP server](https://docs.predicthq.com/ai/mcp) (new): a hosted MCP for searching real-world events by place, date and category, for "what's on this weekend" cards. Uses bearer-token auth.
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) (established): Microsoft's browser automation MCP, so Claude Code can open the Firebase app, swipe cards and test group-voting flows on mobile viewports.
- [Anthropic frontend-design plugin](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/frontend-design) (established): a Claude Code skill that steers UI work toward a deliberate look instead of generic AI styling, useful for polishing Fuse's cards and brand.
