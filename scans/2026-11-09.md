# Fuse daily AI tools scan — 2026-11-09

1. **Mapbox MCP Server v0.17.0** (established project, fresh release Nov 6) — https://github.com/mapbox/mcp-server
   Gives Claude geocoding, POI/category search, directions, isochrones and now in-chat map rendering with live traffic and a results carousel. Handy for prototyping Huntington Village plan-card locations, "how far is this from the group" logic, and checking walk/drive times between venues. Hosted at https://mcp.mapbox.com/mcp or run locally with `npx @mapbox/mcp-server` and a `MAPBOX_ACCESS_TOKEN`.

2. **callstack/agent-device** (established, ~5.3k stars, very active) — https://github.com/callstack/agent-device
   A CLI plus MCP server (`agent-device mcp`) that lets Claude tap, type, screenshot and inspect your Expo app on iOS/Android simulators, emulators, or the web. Where Maestro runs scripted flows, this lets Claude explore the swipe deck and group-match screens itself and report UI bugs. Requires Node 22.12+.

3. **Radon IDE by Software Mansion** (established) — https://github.com/software-mansion/radon-ide
   A VS Code/Cursor extension that turns the editor into a React Native/Expo IDE: embedded device preview, click-to-inspect components, breakpoints, network panel and router integration. Speeds up polishing Fuse's swipe cards and screens without juggling Expo Go and devtools. Check its current licensing terms before adopting it.

4. **gorhom/react-native-bottom-sheet** (established, ~9.1k stars) — https://github.com/gorhom/react-native-bottom-sheet
   The standard Reanimated-powered bottom sheet for React Native. A good fit for plan-card details (hours, map, price) and the group/match panel that slides up over the swipe deck, with smooth gestures that feel native.
