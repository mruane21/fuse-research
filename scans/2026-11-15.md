# Fuse AI Tools Scan: 2026-11-15 (Sun)

Today is a mix for the business-platform pivot (experiments, dashboard UI, ad video) plus one dev-workflow saver. No new Claude Code release since v2.1.325 (fixes only), so it's not a pick.

## Picks

1. **GrowthBook MCP (official)** - https://docs.growthbook.io/integrations/mcp - `Established`
   Open-source feature flags + A/B testing with an official hosted MCP (`https://mcp.growthbook.io/mcp`, OAuth, no key in config; default "human-in-the-loop" mode confirms risky changes). Lets Claude create flags, gate new swipe/plan-card features, and read experiment results. It's also a ready experimentation layer for the ads and analytics product (test ad placements and creatives for businesses).

2. **shadcn/ui MCP server** - https://ui.shadcn.com/docs/mcp - `Established`
   Claude can browse and install shadcn components, blocks and charts from the shadcn registry and third-party registries using plain-English prompts. It's the fastest way to scaffold the web business dashboard (analytics charts, campaign tables, media library) for the platform pivot. It's for web/React, not the Expo app.

3. **HyperFrames (heygen-com/hyperframes)** - https://github.com/heygen-com/hyperframes - `New / trending` (~84k stars, +21k this month, Apache-2.0)
   HeyGen's open-source tool that turns HTML/CSS + media into deterministic MP4s, with a Claude Code plugin and skills. Useful for generating short promo/ad videos from plan cards or business templates (media-management side), and for Fuse launch/social clips. Unlike Remotion (already covered), it works from plain HTML, not React.

4. **Headroom (headroomlabs-ai/headroom)** - https://github.com/headroomlabs-ai/headroom - `New / trending` (GitHub trending today)
   Local context-compression layer for coding agents. `headroom wrap claude` shrinks tool output, logs and JSON before it reaches the model (claims 21-57% fewer input tokens; 90%+ on repeated JSON/logs), and can be undone with `headroom unwrap claude`. It also has an MCP server. This could stretch Claude Code usage on long Firebase log and SQL Connect debugging sessions. Optional, and worth trialing first.

## Claude Code prompt

Run from `C:\Users\User\fuse` in PowerShell, then paste:

```text
Set up today's tools for the Fuse project (Windows/PowerShell, cwd C:\Users\User\fuse). Rules: ask me before changing any app code, package.json, or Firebase config, and before any git commit. Never write API keys as literal values; if anything needs a key, tell me the Windows user env var name to set ([Environment]::SetEnvironmentVariable("NAME","value","User")) and reference it as ${NAME}.

1. GrowthBook MCP (hosted, OAuth, no key): run
   claude mcp add --transport http growthbook https://mcp.growthbook.io/mcp
   Then tell me to run /mcp to finish the OAuth sign-in and choose "Human-in-the-Loop" permissions.
2. shadcn MCP: show me what "npx shadcn@latest mcp init --client claude" will write (it edits .mcp.json) and ask before running it. If I approve, run it, then confirm .mcp.json contains no literal secrets.
3. HyperFrames Claude Code plugin: run
   claude plugin marketplace add heygen-com/hyperframes
   claude plugin install hyperframes@hyperframes
   Note that it needs Node >= 22: check "node -v" and tell me if it's too old (don't upgrade without asking).
4. Headroom (optional): check whether uv is installed. If it is, ask me before running
   uv tool install --python 3.13 "headroom-ai[all]"
   Do NOT run "headroom wrap claude" yourself. Just tell me the command and that "headroom unwrap claude" reverts it.
5. Finish by running: claude mcp list
```
