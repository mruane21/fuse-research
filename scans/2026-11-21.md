# Fuse AI Tools Scan: 2026-11-21

Theme today: tools for the ads, analytics, and media-management side of Fuse.

## Picks

### 1. googleads/google-ads-mcp: official Google Ads MCP server (GitHub, established, official Google)
https://github.com/googleads/google-ads-mcp
- Lets Claude run GAQL reporting queries against Google Ads accounts. It can also make guarded changes (assets, video uploads, labels) through a two-step Propose & Confirm flow. It runs locally over stdio with Application Default Credentials (gcloud).
- For Fuse: a reference for how an ads-analytics product talks to the Google Ads API. It's also an easy way to pull real campaign data while you design dashboards for business customers.

### 2. Pipeboard Meta Ads MCP (established; hosted remote MCP, open-source server)
https://github.com/pipeboard-co/meta-ads-mcp · https://pipeboard.co
- A hosted remote MCP (`https://meta-ads.mcp.pipeboard.co/`) with 30+ tools to analyze, launch, and update Facebook/Instagram campaigns. It has sibling servers for Google, TikTok, Snap, and Reddit Ads, and there's a free plan. Pipeboard says it's a badged Meta Business Partner.
- For Fuse: the quickest way to check Meta ad performance from Claude. It's also a live example of the multi-platform "one login, every ad network" feature Fuse could compete with or plug into.

### 3. Cloudinary plugin + MCP servers (established, official Cloudinary)
https://cloudinary.com/documentation/cloudinary_llm_mcp
- One install: `/plugin install cloudinary@claude-plugins-official`. It sets up Cloudinary skills plus remote MCP servers for uploading, managing, transforming, tagging, and analyzing images and video. Most of the servers sign in with OAuth.
- For Fuse: covers the media-management part of the new direction: business asset libraries, auto-cropped ad creatives in every size, and video transforms. You'd get this without building a media pipeline on Firebase Storage yourself.

### 4. Claude Code v2.1.330 (new, Nov 20)
https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- Adds "easel," which draws charts on request and under MCP metrics results (Pro/Max, macOS/Linux; turn it off in `/config`). Also fixes multi-minute freezes after compaction and in WebFetch, and fixes user settings being lost when several Claude Code processes save at once.
- For Fuse: quick charts from ads/analytics MCP results help when prototyping reports. The freeze fixes help long dev sessions. (On Windows, charts likely won't show, but the fixes apply.)
