## Picks

1. **Google Analytics MCP (official)** - https://github.com/googleanalytics/google-analytics-mcp - `Established`
   Google's official GA4 MCP (~3.8k stars, PyPI `analytics-mcp`). It covers run_report, funnel, conversions/ROAS, and realtime reports, read-only by default. Claude can answer "which plan cards and pages convert?" for the prototype/web, and later it can power GA-backed analytics reports for Fuse business customers.

2. **Workspace MCP v2 (taylorwilsdon/google_workspace_mcp)** - https://github.com/taylorwilsdon/google_workspace_mcp - `New` (v2.0 on Oct 2, latest v2.4.2 on Nov 12)
   One MCP for Gmail, Calendar, Drive, Docs, Sheets, Slides, Forms, Tasks and Chat (~3.5k stars), with tool tiers (core/extended/complete) to keep context small. It's useful for Joe's venue outreach, pitch decks, and partner sheets without leaving Claude.

3. **anthropics/skills** - https://github.com/anthropics/skills - `Established` (GitHub)
   Anthropic's official Agent Skills repo (~194k stars), installable as a Claude Code plugin marketplace. The `document-skills` pack (docx/xlsx/pptx/pdf) lets Claude produce real decks, spreadsheets and PDF one-pagers for venue/advertiser pitches and investor updates.

4. **Notion MCP (official remote)** - https://developers.notion.com/docs/mcp - `Established`
   Notion's hosted OAuth MCP at `https://mcp.notion.com/mcp`, so there's no API key to store. Claude can read and write specs, the roadmap, and venue CRM pages, which gives you and Joe a shared source of truth for the ads/analytics pivot.
