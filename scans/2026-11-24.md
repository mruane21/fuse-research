## Picks

1. **[Snapchat Ads MCP server](https://developers.snap.com/marketing-api/Ads-MCP/Introduction)** (new, official Snap-hosted at `https://mcp.snapchat.com/ads`; [launch post](https://forbusiness.snapchat.com/blog/snapchat-ads-mcp), [Claude Code setup](https://developers.snap.com/marketing-api/Ads-MCP/connect-an-agent))
   Lets Claude read Snapchat Ads campaign setup, performance and diagnostics ("which ad sets changed most week over week?"). For Fuse's ads/analytics side: Snapchat is where a young Long Island audience is, and this is the official read-only feed to pull next to the Google, Meta and TikTok ads MCPs you already have. Read-only for now (write access comes later). OAuth with Snap's registered client id `claude-snap-ads`, no key. An org Admin must approve Claude once.

2. **[ElevenLabs MCP server](https://elevenlabs.io/docs/eleven-api/resources/mcp-server)** (established company; hosted remote MCP at `https://api.elevenlabs.io/v1/mcp`)
   From Claude you can generate voiceovers, sound effects, music, images and video, design voices, and keep brand kits so output follows a business's colors, fonts and logo. For Fuse: quick voiceover and audio for business ad clips and promo videos (pairs with the Remotion/HyperFrames picks you already have), and a model for the media side of the platform. OAuth sign-in, no key. Generations use your ElevenLabs credits. The Claude directory connector is a cut-down version, so add the custom URL for the full toolset. The old open-source `elevenlabs/elevenlabs-mcp` repo is archived, so use the hosted one.

3. **[cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)** (GitHub, MIT, ~71k stars, created Apr 2026, trending today; [gallery](https://cathrynlavery.github.io/diagram-design/))
   A Claude Code skill/plugin that draws 52 diagram types (architecture, sequence, quadrant, flow, timeline...) as one self-contained HTML + SVG file, and can "onboard" to a website to copy its palette and fonts. For Fuse: on-brand diagrams of the Firebase architecture (POC/Test/Prod, Functions, SQL Connect), the swipe-to-match flow, or the ad/analytics product for Joe's pitch decks, with no Mermaid look. Its PRIVACY.md lists what it sends over the network.

4. **[Langfuse](https://github.com/langfuse/langfuse)** (GitHub, established: ~38k stars, open-source LLM observability, self-hostable or cloud; [MCP docs](https://langfuse.com/docs/api-and-data-platform/features/mcp-server))
   Traces, evals, prompt management and cost tracking for LLM calls, plus a native MCP so Claude can inspect traces and prompts. For Fuse: once you add AI features (ad copy, plan suggestions, business insights via Genkit/Firebase AI Logic), it shows what each call cost and returned and lets you version prompts outside the app code. Partial fit until AI features ship. The MCP uses a project API key (Basic auth), and read and write tools are on by default.
