# Fuse AI Tools Scan: 2026-11-16 (Mon)

Today's theme is the business-platform side: design-to-code, dashboard UI, an in-dashboard AI copilot, and media uploads. There's no new Claude Code release since v2.1.325 (fixes only), and Fable 5.2 was already covered on 11-10.

## Picks

1. **Google Stitch MCP + stitch-skills (google-labs-code/stitch-skills)**: https://github.com/google-labs-code/stitch-skills (MCP setup: https://stitch.withgoogle.com/docs/mcp/setup/). `Established` tool, skills `Trending` (GitHub TypeScript trending today)
   Stitch is Google Labs' AI UI designer, and its hosted MCP lets Claude Code generate and edit screens and pull back their HTML and screenshots. The official skills add design and build workflows plus DESIGN.md design-system files. You could quickly mock up business-dashboard screens (campaigns, analytics, media library) in the Fuse brand, then have Claude adapt them into real components.

2. **Tremor (tremorlabs/tremor)**: https://github.com/tremorlabs/tremor (blocks: https://www.tremor.so/blocks). `Established` (Apache-2.0)
   It has 35+ copy-paste React + Tailwind + Radix components built for dashboards: KPI cards, spark charts, bar lists, trackers, date-range pickers and filters. Tremor Blocks adds 300+ dashboard sections and templates. It's purpose-built for the analytics view businesses would see (impressions, swipes, matches per venue) and more metrics-focused than plain shadcn charts. It's for web only (React 18.2+, Tailwind v4), not the Expo app.

3. **CopilotKit + AG-UI protocol (CopilotKit/CopilotKit, ag-ui-protocol/ag-ui)**: https://github.com/CopilotKit/CopilotKit and https://github.com/ag-ui-protocol/ag-ui. `Established` (AG-UI is GitHub TypeScript trending today)
   This is an open-source framework and protocol for embedding an AI agent in your frontend, with chat, shared state, generative UI and human approvals. You could use it for a "talk to your analytics" copilot in the business dashboard, so a venue could ask things like "which plan cards got the most swipes this week?" or "draft an ad for Friday." Its docs include a setup prompt you can hand to Claude Code.

4. **Uppy (transloadit/uppy)**: https://github.com/transloadit/uppy (React docs: https://uppy.io/docs/react/). `Established`
   This is a mature open-source file uploader with drag-and-drop, a dashboard UI, webcam, resumable uploads, and React components and hooks (`@uppy/react`). It covers the upload side of media management (businesses adding photos and videos for plan cards and ads). For Firebase, it would need a custom upload path such as XHR to a Cloud Function or signed URL, because there's no first-party Firebase Storage plugin.
