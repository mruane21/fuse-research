# Fuse AI tools scan — 2026-11-01

1. **[Claude Code v2.1.316](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)** (new, Oct 31). Fixes PowerShell hooks not blocking on exit code 2 when a command starts with a type cast, `param`, `using`, or an attribute, which matters for the "ask before touching app code / package.json / Firebase config" guard hooks on Windows. Also adds `CLAUDE_CODE_SUBAGENT_EFFORT`, and deprecates Opus 4.8 fast mode (removed Nov 30; move to Opus 5.5).

2. **[Yelp/yelp-mcp](https://github.com/Yelp/yelp-mcp)** (established, Yelp's official server). One `yelp_agent` tool for natural-language local business search, details, and comparisons using Yelp's data. Good for seeding and enriching Huntington Village restaurant and bar plan cards (hours, ratings, vibe) without hand-curating. Needs a Yelp Fusion AI API key (free trial).

3. **[microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp)** (established). Lets Claude drive a real browser against the Firebase prototype to click through the swipe and match flow, catch regressions, and grab screenshots for design review.

4. **[ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)** (established, from Google's Chrome team). Gives Claude performance traces, console and network logs, and DOM inspection, which helps you tune swipe-card animation smoothness and load time on mobile Chrome.

Ask me for my Yelp Fusion AI API key, then store it only as a Windows user environment variable with `[Environment]::SetEnvironmentVariable("YELP_API_KEY", "<key>", "User")`. Never write the literal key into any file. Add a `yelp_agent` entry to .mcp.json with command `uv`, args `["--directory", "C:\\Users\\User\\fuse\\tools\\yelp-mcp", "run", "mcp-yelp-agent"]`, and env `{"YELP_API_KEY": "${YELP_API_KEY}"}`. Show me the .mcp.json diff before saving.
5. Finish by running `claude mcp list` and showing me the output.
