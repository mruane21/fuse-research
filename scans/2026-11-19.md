# Fuse AI tools scan — 2026-11-19

1. **[Trigger.dev](https://github.com/triggerdotdev/trigger.dev) + [official MCP server](https://trigger.dev/docs/mcp-introduction)** (established; MCP 2.1 added agent chat, prompt management and run reports — [changelog](https://trigger.dev/changelog/mcp-server-2-1))
   Durable background jobs and AI agents in TypeScript. Good fit for the business side: scheduled ad-performance reports, media processing queues, and campaign sends that are too long for a Cloud Function. Claude Code can start, deploy and debug tasks through the MCP.

2. **[Puck](https://github.com/puckeditor/puck) + [Puck AI 0.9](https://puckeditor.com/blog/puck-ai-09)** (established editor; AI 0.9 is new, Nov 10)
   An open-source drag-and-drop visual editor for React. Businesses could build their own promo/landing pages or ad layouts inside a Fuse dashboard. The new `usePuckAi` hook lets you put a "make me a promo page" chat inside that editor.

3. **[Lago](https://github.com/getlago/lago) + [Lago MCP server](https://getlago.com/docs/guide/ai-agents/mcp-server)** (established)
   Open-source metering and usage-based billing. It can bill businesses per impression, swipe or match (ad spend, credits, hybrid plans) on top of Stripe. The MCP lets Claude query customers, usage and invoices.

4. **[Satori](https://github.com/vercel/satori)** (established, GitHub)
   Turns JSX/HTML+CSS into SVG (then PNG via resvg). You could auto-generate branded plan-card ad creatives, share images and OG cards for each business from one template, running in a Firebase Function.

_Claude Code v2.1.328 (today) is mostly enterprise/self-hosted runner changes. Skipped._
