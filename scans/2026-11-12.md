# Fuse AI tools scan — 2026-11-12

## Picks

1. **Claude Security plugin** (established, Anthropic official) — https://code.claude.com/docs/en/claude-security.md
   Multi-agent vulnerability scan of a whole repo or just a branch diff, with every finding independently verified and optional patches you apply yourself (`git apply`, never automatic). Worth a full pass over Fuse's Firebase Functions, SQL Connect queries and auth flows before Prod launch. Needs `python3` 3.9+ on PATH (on Windows, make sure `python3` isn't the Microsoft Store stub).

2. **MCP reference servers v2.4.0 security release** (new, Nov 11) — https://github.com/modelcontextprotocol/servers/releases/tag/v2.4.0
   Fixes six vulnerabilities: `@modelcontextprotocol/server-filesystem` → 2.3.0, `mcp-server-git` and `mcp-server-fetch` → 2026.11.11 (e.g. a repo's `.git/config` could make the git server run a program). If any of these are in your Claude Code setup, upgrade or unpin them.

3. **RevenueCat AI Toolkit** (established; official plugin + hosted MCP) — https://www.revenuecat.com/docs/tools/ai-toolkit · https://github.com/RevenueCat/ai-toolkit
   One plugin install brings skills plus the MCP at `https://mcp.revenuecat.ai/mcp` (OAuth, no key in files) so Claude Code can set up products/entitlements/paywalls and wire the React Native Purchases SDK. Useful for when you and Joe decide on a premium tier (e.g. bigger groups, boosted plans); it also reads charts and experiments.

4. **Rive React Native 2.0 — `@rive-app/react-native`** (GitHub; established engine, new Nitro runtime published this week) — https://github.com/rive-app/rive-react-native
   Interactive, state-machine animations designed in Rive and driven from code. A good fit for brand moments: the "it's a match" celebration, swipe-card feedback, onboarding mascots. Needs Expo SDK 53+ and a dev build (not Expo Go); the old `rive-react-native` package is now legacy.
