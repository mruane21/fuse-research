# Fuse AI Tools Scan: 2026-11-03

## Picks

### 1. Claude Code v2.1.317 (new, released Nov 2, 2026, evening ET)
https://github.com/anthropics/claude-code/releases/tag/v2.1.317
- This is the first release since v2.1.316. It adds a warning when a `/schedule` cloud task picks up connectors you didn't ask for. It adds an ask-first check before a tool call sends your account email to the network. It also fixes project and local MCP servers disconnecting after the first turn in some desktop sessions.
- For Fuse, the connector warning is worth reading because the daily scan runs as a scheduled job. The MCP disconnect fix also helps if you use the desktop Code tab.
- Related Anthropic news: Messages API "message threads" went to public beta on Nov 2 (https://claude.com/resources/articles/message-threads). Claude Code already uses it by default, so there's nothing to set up. It only matters if Fuse ever calls Claude directly.

### 2. frontend-design plugin, Anthropic official (established, about 1.1M installs)
https://claude.com/marketplace/plugins/frontend-design
Source: https://github.com/anthropics/claude-plugins-official/tree/main/plugins/frontend-design
- It makes Claude choose a design direction first: type, palette, motion, spacing. It then builds UI that avoids the generic AI look.
- For Fuse, it should help keep new screens and swipe-card polish consistent with your brand. Give it your tokens and the sticker/brand assets, since the skill follows the brief.

### 3. Sentry MCP plus Claude Code plugin (established)
https://github.com/getsentry/sentry-mcp (docs: https://docs.sentry.io/product/sentry-mcp/)
- This is a remote MCP server that signs in with OAuth. The plugin adds a `sentry-mcp` subagent that reads real errors, traces and performance data.
- For Fuse, it lets Claude pull a real stack trace from a bug a friend hits when swiping from a shared link. The first time, create a free Sentry project and add the browser SDK. That touches app code, so Claude should ask first.
- When connecting, limit it to one project. The Seer analysis tool is a paid add-on.

### 4. foursquare/foursquare-places-mcp (established, official Foursquare, 2025)
https://github.com/foursquare/foursquare-places-mcp (API docs: https://docs.foursquare.com/data-products/docs/places-api)
- It exposes Foursquare Places search through MCP, with category, hours, ratings, photos and popularity filters. Its 5 tools cover search, geotagging and details.
- For Fuse, it's a way to check how well Foursquare covers Huntington Village before choosing a plan-card data source. It could fill gaps next to the Google/Yelp sources already reported.
- Caveats:
  - The repo hasn't been updated since April 2025, and it has 18 stars.
  - The license shows as "Other".
  - It needs a free Foursquare Service API key, Python 3.13+ and `uv`.
  - Its README only documents Claude Desktop setup on macOS, so the Windows and Claude Code setup below is adapted.
  - Not tested.

### 5. llffhh/GatheringFun (GitHub reference project, MIT, created Jan 2026)
https://github.com/llffhh/GatheringFun
- It is a React 19 + Vite + Tailwind 4 + Framer Motion app on Firebase Firestore with anonymous auth. It has swipe cards, a Google Places (New) search and real-time popularity ranking.
- For Fuse, it's a reference for anonymous join-by-link voting, Firestore session structure and live tally logic.
- It has 0 stars, so treat it as a code reference, not a dependable library.
- Also seen: https://github.com/v7h-lab/GroupTable. It is a similar React/Firebase/Yelp-AI app, but it has no license, so read it for ideas only.
