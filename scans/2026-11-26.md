# Fuse AI tools scan — 2026-11-26

No new Claude Code release since v2.1.332 (covered yesterday).

## Picks

1. **Microsoft Clarity + Clarity MCP** (established; MCP updated Nov 17) — https://github.com/microsoft/clarity-mcp-server · [docs](https://learn.microsoft.com/en-us/clarity/third-party-integrations/clarity-mcp-server)
   Free heatmaps and session recordings with an official MCP that signs in through OAuth, so no key is needed. Claude can ask things like "show mobile sessions where users rage-clicked on the swipe deck", and there's a [React Native SDK](https://learn.microsoft.com/en-us/clarity/mobile-sdk/react-native-sdk) for the Expo app. That makes it a cheap UX-analytics layer for the prototype and the coming business dashboard.

2. **MCP Tasks + Elicitation GA, Skills over MCP, File Uploads** (new, Nov 24) — https://claude.com/resources/articles/skills-over-mcp-tasks-and-more · SDK: https://github.com/modelcontextprotocol/typescript-sdk
   With Tasks, servers can run long background jobs, and with Elicitation a server can pause to ask the user to confirm (Supabase uses it to confirm costs). If Fuse becomes ad/analytics software, a "Fuse for Business" MCP server is a strong selling point: businesses could ask Claude for campaign stats, start long report exports, and confirm ad spend safely.

3. **Fabric.js** (GitHub, established, ~31.6k★, active) — https://github.com/fabricjs/fabric.js
   This is the go-to canvas library for in-browser image and creative editors (text, stickers, crops, export to PNG or SVG). It could power a "make your ad" editor where businesses drop a logo and photo onto branded Fuse plan-card templates.

4. **imgproxy** (GitHub, established, ~11.2k★) — https://github.com/imgproxy/imgproxy · [docs](https://docs.imgproxy.net/)
   A fast, self-hosted server that resizes, crops and converts images (WebP/AVIF) on the fly through signed URLs. It could run on Cloud Run in front of Firebase Storage to serve business media at every card size without paying for Cloudinary.
