# Fuse AI tools scan — 2026-11-20

1. **[fal MCP server](https://fal.ai/mcp)** (established platform, hosted MCP; [Claude Code setup](https://fal.ai/docs/documentation/setting-up/mcp/claude-code))
   One hosted MCP for 1,000+ image, video and audio models, with browser sign-in and no API key. Claude Code can draft ad creatives, short promo videos and product shots for businesses on Fuse, check a model's price before running it, and help prototype a "generate my ad" feature for the media side.

2. **[Twenty CRM](https://github.com/twentyhq/twenty) + [built-in MCP](https://docs.twenty.com/user-guide/ai/capabilities/mcp)** (established, open source, GitHub)
   An open-source Salesforce alternative with an MCP at `https://<workspace>/mcp` (OAuth, read/write). Joe could track Huntington Village business leads, deals and onboarding there, and Claude could query or update the pipeline. Self-hostable on Postgres if you want to own the data later.

3. **[Umami](https://github.com/umami-software/umami) + [Umami MCP](https://umami.is/blog/introducing-umami-mcp)** (established analytics; MCP is fairly new, Sept 2026)
   Privacy-first, cookie-free web and product analytics with campaigns, funnels, retention, revenue and Core Web Vitals. A light option for the marketing site and the business dashboard, or for per-business stats. The MCP is read-only (Cloud: `https://cloud.umami.is/mcp`, needs a Pro API key; self-hosted: set `MCP_ENABLED=1`).

4. **[Claude Code v2.1.329](https://github.com/anthropics/claude-code/releases/tag/v2.1.329)** (new, released Nov 19)
   `/mcp` now shows a "Server message" row with the error text when a remote HTTP MCP refuses to connect, which helps when adding fal, Twenty or Umami. `/tasks` now lists scheduled tasks and `/loop` wakeups, the trust dialog says where a folder's hooks are declared, and a bug that could reset `~/.claude.json` to defaults is fixed.

## Claude Code prompt

```text
I'm on Windows/PowerShell in C:\Users\User\fuse. Set up these tools for Fuse. Rules: ask me before changing any app code, package.json, or Firebase config, and before any git commit. API keys go only in Windows user env vars, referenced as ${VAR} in .mcp.json, never as literal values.

0) Run `claude update` and confirm the version is 2.1.329 or newer.
1) fal MCP (OAuth, no key): run `claude mcp add --transport http --scope project fal https://mcp.fal.ai/mcp-relay`. Tell me to run /mcp, pick fal and choose Authenticate. Then, without generating anything, list 3 fal models suited to a 1080x1920 promo image and a 10-second promo video for a local restaurant, with their prices.
2) Twenty CRM MCP: ask me for my Twenty workspace host (e.g. mycompany.twenty.com). Set it with [Environment]::SetEnvironmentVariable("TWENTY_WORKSPACE_URL","<host>","User"). Add to .mcp.json: "twenty": {"type":"http","url":"https://${TWENTY_WORKSPACE_URL}/mcp"} (OAuth, no key). If I don't have a workspace yet, skip it and tell me how to make one at https://twenty.com.
3) Umami MCP: ask whether I use Umami Cloud (Pro) or self-hosted. Ask me for the API key and set it with [Environment]::SetEnvironmentVariable("UMAMI_API_KEY","<key>","User") (and UMAMI_MCP_URL = https://cloud.umami.is/mcp, or https://<my-umami>/mcp for self-hosted). Add to .mcp.json: "umami": {"type":"http","url":"${UMAMI_MCP_URL}","headers":{"Authorization":"Bearer ${UMAMI_API_KEY}"}}. If I don't use Umami yet, skip it and write a short note on adding its tracking script to the Fuse web app, then wait for my OK.
4) Tell me to restart PowerShell/Claude Code so the new env vars load, and remind me that /mcp shows a "Server message" row if a remote server refuses to connect.
Finally run `claude mcp list` and show me the output.
```
