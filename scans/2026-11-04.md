## Today's picks

1. **Google Maps "Maps Experience agent tools" official MCP server** (formerly Maps Grounding Lite): **new/renamed, docs updated Nov 2** — https://developers.google.com/maps/ai/maps-experience-agent-tools
   Hosted MCP at `https://mapstools.googleapis.com/mcp` with `search_places`, `lookup_weather`, `compute_routes`, `resolve_names`, `resolve_maps_urls`. For Fuse: pull real Huntington Village restaurants/bars with hours, addresses, Place IDs and Maps links to prototype or seed plan cards, plus travel time between stops for multi-stop plans. Needs a Google Cloud project with billing + API key (10,000 free Essentials requests/month, then $7/1,000; a free Maps Demo Key exists for prototyping). Google requires source attribution and has Maps content caching/storage limits, so check the terms before saving results into Firestore. (Different from the previously reported cablate community server; this one is Google's own.)

2. **nexu-io/open-design** (GitHub, Apache-2.0, ~105k stars, release v0.27.0 shipped today): **established, very active** — https://github.com/nexu-io/open-design
   Open-source, local-first AI design workspace (prototypes, landing pages, decks, images, motion) with 100+ skills and 150+ `DESIGN.md` design systems, plus a stdio MCP server so Claude Code can read your design projects' tokens/components/HTML live. For Fuse: quickly explore swipe-card and onboarding layouts or a Huntington launch landing page/deck in your brand, then hand the HTML to Claude Code to port into the Firebase app. Windows x64 desktop app available from the repo releases. Note: README says scrubbed safety/reliability telemetry is always on and analytics is consent-gated.

3. **Claude Design design-system sync (`/design-sync` in Claude Code)**: **established (beta, Pro/Max/Ultra/Team/Enterprise)** — https://support.claude.com/en/articles/14604397-set-up-your-design-system-in-claude-design
   Run `/design-sync` and Claude Code reads your repo's tokens and components and uploads them as a design system that Claude Design uses for new designs and decks. For Fuse: lock in the Fuse brand (colors, type, card components) once so mockups, pitch decks and landing pages for Joe stay on-brand. Anthropic says it works best for React-style component libraries; if the prototype is plain HTML/CSS, build the system from a chat with your brand assets instead.

4. **Message threads (Claude Messages API, public beta)**: **new, Nov 2** — https://claude.com/resources/articles/message-threads
   Send the conversation once, then only new messages plus the previous response ID; Anthropic reports about 35% lower median time-to-first-token on 500K-1M-token requests and says it is already on by default for most Claude Code users. No setup needed for Claude Code. For Fuse it only matters if you later add a Claude-powered feature (e.g., a plan-suggestion chat); the beta header is `message-threads-2026-08-12`, and it is not eligible for zero-data-retention setups. Details: https://platform.claude.com/docs/en/release-notes/overview

Nothing else met the bar today (Calibre MCP, Thunder Client MCP v2 and SonarQube MCP 1.31 shipped this week but are account/VS Code-extension dependent and less relevant right now).
