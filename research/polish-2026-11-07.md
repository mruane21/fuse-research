# Fuse polish research: from "vibecoded" to clean (Nov 7, 2026)

Source: the live prototype. The old link now redirects to **https://fuse-poc.web.app** (landing) and **/app-e/** (Expo web build). I checked the landing CSS and the app bundle. Counts come from the bundle, so some library code is mixed in.

## 1) What already looks good
- Custom type: Outfit and Inter Tight. Default fonts are not a problem here.
- No emoji icons. Icons are SVG.
- Coral (#FF6B4D) on near-black is a clear brand, and the "sticker" motif works.
- Reanimated and a reduce-motion setting show up, there are some haptics, focus rings on the landing page, and accessibility labels.

## 2) Remaining tells (what still reads as "AI-built")
1. **Token sprawl.** The bundle has about 15 font sizes, 16 border radii, 41 hex colors and 87 different padding/margin values. A polished app uses about 6 type sizes, 3 radii and a 4/8pt spacing scale. This is the biggest tell.
2. **Hardcoded hex values in components.** The colors aren't all pulled from one theme, so the same surface ends up a few shades off between screens.
3. **Dark-gray sameness.** #171717, #1C1C1C, #232323 and #2E2E2E are close together, so the layers blur. Use 3 clearly separated surface levels.
4. **Generic overlays and shadows.** The black-to-transparent gradient scrims and big soft shadows are the stock "AI landing page" look.
5. **Inconsistent motion.** One cubic-bezier is reused everywhere, and swipes, matches and sheets have no shared spring language.
6. **States.** Check empty states (no matches, no friends, no location permission), error states and the first-load skeleton on every screen, not just the main one.
7. **Web-first feel.** It's tested on the web build. Native sheets, menus, toasts and keyboard handling are what make it feel like an app.

## 3) Recommended additions
**Already have (keep using):** HeroUI Native, Figma MCP, Mobbin, Anthropic frontend-design skill, Impeccable (https://github.com/pbakaus/impeccable).

**Tokens and system**
- Unistyles 3: https://www.unistyl.es. Typed theme tokens plus breakpoints with near-zero runtime cost. Pairs with HeroUI.
- NativeWind: https://www.nativewind.dev. Use it only if HeroUI's Tailwind setup already relies on it. Pick one styling system.
- Tamagui: https://tamagui.dev. Full token/theme compiler. Heavy, so treat it as an alternative, not an addition.
- Style Dictionary: https://styledictionary.com. One tokens JSON exported from Figma becomes TS for the app and CSS for the landing page.

**Motion and feel**
- Reanimated (have it): https://docs.swmansion.com/react-native-reanimated/. Define 2–3 shared spring presets.
- Gesture Handler: https://github.com/software-mansion/react-native-gesture-handler. Physical, interruptible swipe cards.
- Moti: https://moti.fyi. Declarative enter/exit animations and a built-in Skeleton.
- Skia: https://shopify.github.io/react-native-skia/. Match-moment effects like confetti, glow and blur.
- Rive: https://rive.app/docs/runtimes/react-native/react-native. Interactive brand animations such as the sticker pop and the match screen.
- Lottie: https://github.com/lottie-react-native/lottie-react-native. Cheap empty-state illustrations.
- expo-haptics: https://docs.expo.dev/versions/latest/sdk/haptics/. Use one haptic map: swipe = selection, match = success, error = error.

**Native-feel components**
- Gorhom Bottom Sheet: https://github.com/gorhom/react-native-bottom-sheet. Plan details and filters in proper sheets.
- Zeego: https://github.com/nandorojo/zeego. Real iOS/Android context and dropdown menus.
- sonner-native: https://github.com/gunnartorfis/sonner-native. Polished toasts.
- Burnt: https://github.com/burnt-labs/burnt. Native iOS alerts and toasts.
- Keyboard Controller: https://github.com/kirillzyusko/react-native-keyboard-controller. Smooth chat and inputs.
- expo-blur: https://docs.expo.dev/versions/latest/sdk/blur-view/. Frosted tab bar and headers in place of flat scrims.
- FlashList: https://shopify.github.io/flash-list/. Lists that don't stutter.
- expo-image: https://docs.expo.dev/versions/latest/sdk/image/. Blurhash placeholders and fade-in for Places photos.

**Icons and type**
- Phosphor RN: https://github.com/phosphor-icons/react-native. Six weights including "fill" and "duotone", which suit the sticker vibe.
- Lucide RN: https://lucide.dev/guide/packages/lucide-react-native. Clean alternative. Pick one set.
- Expo fonts guide: https://docs.expo.dev/develop/user-interface/fonts/. Embed fonts via the config plugin so text doesn't flash on load.

**Review, accessibility, regression**
- eslint-plugin-react-native-a11y: https://github.com/FormidableLabs/eslint-plugin-react-native-a11y. Lint for missing labels and roles.
- react-native-owl: https://github.com/FormidableLabs/react-native-owl. Visual-regression screenshots to catch spacing drift.
- Apple HIG: https://developer.apple.com/design/human-interface-guidelines/ and Material 3: https://m3.material.io. Reference for spacing, touch targets (44pt) and type ramps.
- mobile-mcp and Argent (have them). Let Claude screenshot every screen for the audit.
